# Product

Maplora is a self-hosted, single-user hierarchical mind-map editor for organizing thoughts, planning and brainstorming.

The browser renders a tree with one central root distinguished by its size, bold text, stronger border and themed accent background, branches on both sides, inline node editing, keyboard navigation, sibling reordering with shortcuts or dragging, branch moves by dragging onto a new parent, node options on selection with per-node colors and connector styling, collapse/expand and pan/zoom. Re-centre root in the toolbar or Home pans to the measured root center without changing zoom or saving. Non-root default node backgrounds follow a six-color depth palette per theme; custom backgrounds take precedence over both the palette and root accent. Light/dark controls persist the browser preference and otherwise default to the system scheme at startup. Map management includes creation, renaming, duplication, trash and restoration. The library filters titles locally as you type and offers date/title sorting with a browser-persisted preference. Library cards support up to 20 tags with autocomplete and immediate saving; a tag filter matches all selected tags together with title search and sorting without extra requests. The editor copies the full map, including collapsed branches, to the clipboard as Markdown, exports portable JSON files, and downloads complete PNG images at 2× resolution on a white background without editor controls. PNG export expands a separate tree copy and preserves the live editor state. The library imports validated JSON as independent maps, preserving node IDs unless they conflict with active or trashed maps. Undo/redo restores the last 50 node operations with toolbar controls and Ctrl/Cmd shortcuts, saving each change through the existing queue. Changes save automatically as versioned JSON files on the host filesystem. Ctrl+S / Cmd+S works throughout the editor, including inputs and dialogs, suppresses browser page saving and retries failed changes through the existing queue without duplicating an ongoing save or confirming unfinished edits.

The MVP has no database, accounts, authentication or external services. Deployment is one Docker Compose service. Data remains portable by copying the complete data directory, including trash.

The authoritative scope is `.kiro/specs/maplora/requirements.md`, with architecture in `design.md` and implementation progress in `tasks.md`. Post-MVP duplication, sibling reordering, branch moves, visual customization, light/dark themes, JSON import/export, PNG export, library search/sorting, Copy as Markdown and depth-based node colors are implemented. Undo/redo, map tags, root prominence/re-centering and the global save shortcut are implemented. Colored tags and the recently opened maps bar remain planned (tasks 30–31).
